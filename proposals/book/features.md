# Features

What untaped must do or support. Each is a mechanic; a use of it is a case, never the feature. Agreed with the owner on 2026-11-12.

- (q3f) What untaped reports a [plugin] fills is what its folder said when untaped last read it, and what its [staying] [instance] states now.

- (gqx) An [instance] that hangs, crashes or is slow affects only the asks it is part of and the asks made for them.

- (gsr) untaped passes on the [content] of an ask that an [instance] answers without looking into it or keeping it.
- (f6m) A mistake in a [plugin]'s folder affects no other [plugin], and nothing else that the same [plugin] fills.
  - against: One plugin's folder holds a file that cannot be read, and untaped does not start.
  - against: A plugin's folder holds one contract file with a mistake in it, and none of that plugin's contracts is answered.
  - fine: The only keychain installed has a mistake in its contract for getting a secret; an ask for a secret is told that nothing could answer and which lines differ, and every ask that needs no secret is answered as before.
