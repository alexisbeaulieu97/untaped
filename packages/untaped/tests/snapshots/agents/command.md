# acme widgets add
untaped VERSION · untaped-acme 2.3.4 · ENV
Add a widget. (changes things)

A widget with that name already there is reported `unchanged`.

## Usage
`untaped acme widgets add NAME [OPTIONS]`

- `NAME`: The widget's name.
- `--size`: How big it is. Default: `3`.
- `--format`, `-f`: Output format. One of `json`, `yaml`, `table`, `raw`, `pipe`. Default: `table, or UNTAPED_FORMAT / ui.format`.
