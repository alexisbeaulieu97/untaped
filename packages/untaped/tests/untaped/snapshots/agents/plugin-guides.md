# acme
untaped VERSION · untaped-acme 2.3.4 · ENV
Manage widgets.
Details of a topic (a command or a guide): `untaped agents acme NAME`

## Commands
- `widgets list`: List every widget.
- `widgets add`: Add a widget. (changes things)
- `widgets drop`: Drop widgets for good. (destructive)
- `beta` [experimental]: Try the next thing.

## Guides
- `lifecycle`: Read before adding or dropping widgets: how a widget's life runs.

## Settings (`profiles.<name>.acme`)
- `widgets_dir` (path, default `~/.acme/widgets`): Where widgets live.
- `colour` (text, default `blue`): The colour of a new widget.
