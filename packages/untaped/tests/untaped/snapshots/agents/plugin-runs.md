# check
untaped VERSION · untaped-check · ENV
Details of a command: `untaped agents check COMMAND`

## Usage
Check the files you are in. (changes things)

Exit 3 when a check fails.

`untaped check [PATHS...] [OPTIONS]`

- `PATHS...`: Only these files.
- `--strict`: Fail on warnings too.

## Examples

```console
$ untaped check --strict
```

## Commands
- `list`: List every check.
