# acme
untaped VERSION · untaped-acme · ENV
How these pages are organized: `untaped docs`.

Manage widgets on racks.

A rack's widgets come from the plugins that fill its extension point.

## Read first
- `untaped docs acme guides finish`: Read before choosing a finish: what each one does to a widget.
- `untaped docs acme guides selection`: Read before picking widgets: every one, or those named.

## Sections
- `commands` (4): what you can run. `untaped docs acme commands`
- `inputs` (1): the files you write for acme commands. `untaped docs acme inputs`
- `outputs` (1): the rows acme commands print. `untaped docs acme outputs`
- `settings` (2): the `acme:` section of config.yml. `untaped docs acme settings`
- `extensions` (1): the extension points acme offers other plugins. `untaped docs acme extensions`
