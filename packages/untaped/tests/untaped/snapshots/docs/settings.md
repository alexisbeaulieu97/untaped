# acme settings
untaped VERSION · untaped-acme · ENV
How these pages are organized: `untaped docs`.

The `acme:` section of `CONFIG`. A named profile sets any of them under `profiles.<name>.acme`; `untaped config set acme.KEY VALUE` changes one.

- `widgets_dir` (path, default `~/.acme/widgets`): Where widgets live.
- `colour` (text, default `blue`): The colour of a new widget.
