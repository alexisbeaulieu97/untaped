`untaped-awx`'s skill is now a stub: `untaped skills install awx` writes a
short skill that sends the agent to `untaped agents awx`. What the old skill
said now lives in the commands' own help, the record fields' descriptions
(`untaped plugin schema awx.test_result` describes every field of a test
result row), and guides on selecting and changing resources, export and
apply documents, workflow node graphs, launching, linting, and writing and
reading test suites.
