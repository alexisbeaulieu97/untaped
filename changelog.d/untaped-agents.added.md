`untaped agents` prints what this untaped can do as Markdown pages for coding
agents: `untaped agents` is the map of core and every installed plugin,
`untaped agents PLUGIN` a plugin's commands, extension points and settings,
and `untaped agents PLUGIN COMMAND` a command's options and examples. Each
page names the untaped that answered, and says when the folder's
`pyproject.toml` requires another one
([agent-pages.md](https://github.com/alexisbeaulieu97/untaped/blob/v11.1.0/docs/reference/agent-pages.md)).
