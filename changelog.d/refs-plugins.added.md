An install's reference now lists the plugins it composes (`plugins`, written
even when empty), by `setup register` and kept current by the install's
runs: the first start after an install change and each store open. So
`setup prune` keeps the folder of a plugin another install sharing the home
uses, and keeps every folder while a live install's reference has no list.
`write_reference` in `untaped.sdk.testing` takes `plugins=` (`None` leaves
the key out).
